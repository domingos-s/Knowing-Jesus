# Knowing Jesus

A mobile-first progressive web app for exploring Christian beliefs about Jesus, faith, prayer, church, and baptism through Scripture references, discussion, reflection, and journaling.

## Design principles

- Encourage open questions and honest answers.
- Present core Christian beliefs clearly without treating any response as a required outcome.
- Keep the baptism section separate from lesson completion.
- Preserve the learner's ability to believe, remain unsure, learn more, or decline.
- Store personal reflections only on the device.

## Features

- 12-part learning path
- Bible reading references
- Age-accessible explanations of Christian beliefs
- Discussion and reflection prompts
- Private on-device journal
- Persistent Question Box
- Lesson completion and progress tracking
- Separate baptism discussion section
- Offline-capable PWA shell
- No accounts, analytics, ads, or remote data collection

## Privacy

Journal entries, answers, questions, and progress are stored locally in the browser using `localStorage`. Nothing is transmitted by the app.

## Development

This is a static application with no build step. Serve the repository root over HTTPS or a local static web server.
